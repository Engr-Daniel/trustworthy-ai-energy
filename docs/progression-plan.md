# Progression milestones

This is the acceptance-criteria companion to the single active [task ledger](../task.md). The current protocol remains a draft; stages describe planned work, not completed searches or screening.

| Stage | Work | Ready to advance when |
| --- | --- | --- |
| 1. Eligibility calibration | Retrieve abstracts for the existing 20-record packet; document human reviewer arrangement; record independent decisions where available and reconcile ambiguous rules | Each record has evidence or a documented retrieval failure; reviewers, dates and rationale are recorded; rule changes are logged |
| 2. Protocol and search readiness | Resolve source access, publication/language/date rules and version policy; validate platform syntax against known eligible items; finalise/version the protocol and record registration status | Exact tested queries, known-item results, access limits and prospective changes are saved |
| 3. Complete identification | Execute the planned accessible subject sources and citation tracing; retain complete exports, search dates, errors and hashes; import occurrences with stable IDs | Every executed source has an auditable export and counts; unavailable sources are disclosed; deduplication and preliminary version linkage are reviewed |
| 4. Formal screening | Extend validation for confirmed decisions before using the ledger; screen titles/abstracts then full texts; record reasons, reviewer arrangement and unresolved conflicts | All records have a traceable disposition; retrieval failures are distinguished from exclusions; counts reconcile |
| 5. Charting calibration and extraction | Pilot the extraction form on 10 diverse papers; revise codebook; extract with page/table/figure evidence locators and audit | Extraction rules are consistent; unknowns are explicit; reports are linked to verified studies before synthesis counts |
| 6. Evidence map and review contribution | Map tasks, modalities, contexts and reliability evaluation; separate benchmark evidence from deployment evidence; compare existing reviews | Conclusions trace to extracted studies; limitations and overlap are explicit; no title-only gap claims remain |
| 7. Original-project gate | Assess a candidate using the existing novelty gate and project template | A dated continue/redefine/stop decision covers closest work, data rights, split independence, compute, baselines and evaluation |
