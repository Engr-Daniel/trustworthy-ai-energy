# Novelty and feasibility gate
No technical project is approved yet.

Before implementation record:
1. Five or more genuinely close original studies compared in full text.
2. Distinct contribution and specific industrial decision.
3. Public data with compatible labels and leakage-safe grouping.
4. Feasible models, baselines, calibration budgets and compute.
5. Prespecified risk definitions, review workloads and uncertainty analysis.
6. What a negative result would teach.

Outcome: continue, redefine or stop. Record evidence and dated rationale.
A paper title, model combination or new dataset alone does not establish novelty.
