# Programme charter
Owner: Daniel Oyewale
Programme: Trustworthy AI for Energy and Industrial Systems
Working repository name: trustworthy-ai-energy

## Purpose
Investigate specific reliability failures in industrial visual inspection and develop publishable evidence and a reproducible applied-research portfolio.

## Workstreams
- Review paper: scoping and novelty assessment active.
- Corrosion inspection: priority candidate, no approved implementation.
- Thermal and visual inspection: alternative requiring paired-data feasibility.
- Evidence-grounded reporting: parked pending a defined task and evidence rubric.

## Approval rule
Literature assessment, distinct contribution, usable public data, modest compute and an evaluation protocol precede technical implementation.
Repository setup and documentation are active research work and do not require a project to pass the implementation gate.

## Current state
The seed corpus and data audits are in review-paper/.
No model experiments have been run.
GitHub repository creation is pending. Connected tools can inspect/edit repositories but expose no create-repository operation.
