# Manuscript figures

Place final figure files here, preferably vector PDF for diagrams and charts or suitable high-resolution PNG for raster material. Keep editable sources and provenance alongside final exports where appropriate.

The scaffold renders empty boxes without external image files. Replace each `\figureplaceholder{...}` with `\includegraphics[width=\columnwidth]{filename}` once the figure is supported by the completed work. A wide figure can use `figure*` and `\textwidth`.

Planned placeholders: conceptual scope, selection flow, evidence distribution, reliability coverage matrix and an optional evidence-derived framework. These are planned outputs, not completed results. Confirm reuse permissions for third-party material.
