# Generated manuscript figures

make_figures.py generates fig_flow, fig_evidence, fig_maturity and fig_years as PDF and PNG, plus figure-data.json. Regenerate from records; do not edit numbers in the graphics. The flow explicitly includes pending title/abstract and retrieval stages. The evidence-map graphics refer only to the 157-study assessed subset and remain provisional.

Vector PDFs are the manuscript inputs; PNGs are preview copies. These are original review figures, distinct from copyrighted source-paper PDFs kept outside Git.
